# MemeticBox Optimizer

Готовые настройки, которые убирают лаги в **MemeticBox**. На тестовом ПК FPS вырос до ~400.

> Неофициальный мод. Проект не связан с авторами игры (Corvium Games). Файлы игры (`.exe`, `.dll`) в репозитории не лежат, меняются только текстовые конфиги.

## Что внутри

```
MemeticBox_Optimizer/
├── 0_ORIGINAL_BACKUP/            оригинальные файлы для отката
├── 1_OPTIMIZE_main/              основной пресет (ставь его)
│   └── settings.ini
├── 2_POTATO_if_still_laggy/      пресет для слабых ПК
│   └── settings.ini
└── 3_OPTIONAL_lite_weapons/      необязательно: облегчённое оружие
    └── assets/weapons/*.txt
```

## Установка

1. **Закрой игру.** Если она запущена, при выходе она перезапишет `settings.ini` обратно.
2. Скачай репозиторий: **Code → Download ZIP** и распакуй.
3. Скопируй `settings.ini` из папки `1_OPTIMIZE_main` в папку игры (рядом с `MemeticBox.exe`) с заменой.
4. Запусти игру.

Папку с игрой в Steam можно открыть так: **Библиотека → MemeticBox → ПКМ → Управление → Просмотреть локальные файлы**.

## Пресеты

| Параметр | Оригинал | `1_OPTIMIZE_main` | `2_POTATO` |
|---|:---:|:---:|:---:|
| `shadows` (тени) | 1 | **0** | **0** |
| `vsync` (верт. синхронизация) | 1 | **0** | **0** |
| `renderScale` (масштаб разрешения) | 1.00 | **0.75** | **0.50** |
| `postfx` (пост-обработка) | 0 | 0 | 0 |
| `bloom` | 1 | **0** | **0** |
| `ssao` (затенение) | 1 | **0** | **0** |
| `fxaa` (сглаживание) | 1 | **0** | **0** |
| `wet` (мокрые поверхности) | 1 | **0** | **0** |

Что сильнее всего влияет на FPS: тени, масштаб разрешения и vsync. Если FPS ниже частоты монитора, vsync режет его ступеньками (60 → 30), поэтому его выключили.

`profile.ini` (управление, скины, статистика) пресеты **не трогают**.

## Необязательно: облегчённое оружие

Папка `3_OPTIONAL_lite_weapons` меняет **геймплей**, ставь её только если лаги остались.

- `max_meat` уменьшен вдвое (меньше кусков мяса за выстрел)
- `crater` уменьшен на 25% (меньше дыры от попаданий)

Меньше физических объектов и разрушений, значит меньше нагрузка на процессор. Скопируй папку `assets` в папку игры с заменой.

## Откат

Скопируй файлы из `0_ORIGINAL_BACKUP` обратно в папку игры с заменой. Или удали `settings.ini`, и игра создаст настройки по умолчанию.

## Если FPS слишком высокий и хочется красоты

Включай эффекты обратно в меню игры по одному и смотри на FPS в заголовке окна:

1. Тени (самое заметное, но самое тяжёлое)
2. Масштаб разрешения до 1.0
3. Bloom и FXAA (почти ничего не стоят)

## Если лаги растут со временем

В заголовке окна игры показаны FPS и счётчики **объекты / кубы / частицы**. Если лаги нарастают, эти числа растут. Помогает:

- очистка гора (по умолчанию клавиша `Delete`)
- перезапуск карты
- карты больше 160 м игра сама помечает как тяжёлые, они грузят сильнее

## FAQ

**Масштаб разрешения ничего не меняет.**
Возможно, он работает только при включённой пост-обработке. Включи **Post-processing** в меню игры, а bloom, SSAO и FXAA оставь выключенными.

**Игра сбросила настройки.**
Ты копировал файл при запущенной игре. Закрой игру и скопируй снова.

**Это безопасно?**
Меняются только текстовые `.ini` и `.txt` файлы настроек. Исполняемые файлы не затрагиваются.
